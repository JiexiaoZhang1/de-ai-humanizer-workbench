# Python project rewrite profile

Use this profile for technical prose influenced by Python implementations.

- Preserve module names, class names, function names, command examples, exceptions, and file paths.
- Describe data flow and side effects with concrete verbs.
- Keep input constraints, return behavior, and failure cases precise.
- Remove vague claims about simplicity, robustness, intelligence, or production readiness unless supported.
- Do not invent dependencies, benchmarks, types, tests, or platform support.
- Keep code-related wording concise without flattening important operational details.
- Maintain the distinction between local processing and external API calls.
- Preserve paragraph order and all protected technical tokens.
- Use readable developer-facing English, not documentation boilerplate.
- Return only the rewritten prose.

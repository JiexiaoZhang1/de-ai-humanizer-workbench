# Web application rewrite profile

Use this profile for product, interface, API, and web-application prose.

- Preserve component names, routes, events, state names, package names, and configuration values.
- State user actions and system responses in a clear order.
- Replace vague benefit claims with the concrete behavior described by the source.
- Keep accessibility, privacy, validation, and error-handling details intact.
- Do not convert implementation facts into marketing claims.
- Avoid repetitive feature-list rhythm when the source is continuous prose.
- Keep causal and conditional relationships explicit.
- Do not invent browser support, performance results, integrations, or deployment guarantees.
- Preserve paragraphs and information density.
- Return only natural English prose.

# Reference application rewrite profile

Use this profile when an application or repository is being treated as design reference material.

- Extract only general editorial principles; do not imitate branding or copy project-specific wording.
- Preserve the source text's actual product names, responsibilities, limitations, and operational details.
- Separate observed behavior from interpretation.
- Remove unsupported superlatives and generic claims about quality or ease of use.
- Keep descriptions concrete enough that a reader can understand what happens and who initiates it.
- Do not invent features based on common patterns in similar applications.
- Retain privacy, attribution, and licensing statements where present.
- Preserve paragraph count and factual anchors.
- Use neutral, direct prose appropriate for a product or engineering audience.
- Return only the revised text.
